Context provider for auth

The host wraps content in a tiny <x-auth-provider> element. Children (including federated remotes) find it with this.closest('x-auth-provider') and read the session signal + an authed-fetch helper. This is just the platform's "ancestor lookup" — no framework primitive needed beyond signals.

Login

Federated widget that reads the session

Loaded from widgets/private-info.js — a separate bundle. It walks up to the provider, subscribes to the session signal, and uses the provider's fetchAuthed to make authenticated requests.
