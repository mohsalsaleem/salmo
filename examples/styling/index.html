Styling

Three patterns: page CSS (light DOM), a scoped <style> block (shadow DOM), and reactive styles via classMap + styleMap. Everything lit-html does for styling works here unchanged — we just re-export the directives.

1. Light DOM + page CSS

Default rendering goes into the host's light DOM. Page CSS targets it normally (x-light-demo .pill, etc).

2. Shadow DOM with a scoped <style>

shadow: true opts into Shadow DOM. A <style> block in the template only applies inside the component — try opening DevTools and inspecting; the rule below doesn't leak to the page.

3. Reactive: classMap + styleMap

Toggle classes and inline styles from signals. Click the buttons.
